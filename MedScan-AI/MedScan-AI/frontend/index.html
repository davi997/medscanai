Built to be useful and honest about its limits

MedScan AI shows what the model produced and what that output means, instead of dressing numbers up as diagnoses.

Real inference only

Results come from a pre-trained network running on the server. If a model is missing or fails, you get an error, never a made-up score.

Grad-CAM explanations

See which image regions drove the model's strongest finding. It shows where the network looked, not a confirmed lesion.

Scores with context

Each finding is plotted against the operating threshold published with the model, and labelled as an uncalibrated score.

PDF reports

Export examination details, images, findings, model information and the full disclaimer in one document.

Careful uploads

Files are checked by content, size and format, then re-encoded. Original filenames and metadata are not stored.

Modular by task

Each imaging task has its own model behind a common interface, so new validated models can be added without touching the rest.

How it works

  1. Choose a task

    Pick the imaging category. Unavailable tasks are marked and cannot be selected.

  2. Upload the image

    The file is validated and sanitised on the server before anything runs.

  3. Model analysis

    The image is preprocessed and passed through the task's model, with Grad-CAM for the top finding.

  4. Review and export

    Read findings, scores and limitations, then download a PDF report.

About MedScan AI

MedScan AI is a graduation project for Medical Informatics. It demonstrates how a clinical-style imaging workflow can be assembled from open components: a FastAPI service, a PostgreSQL database, PyTorch models and a framework-free web interface.

The first module uses the open-source TorchXRayVision library. It was not developed or validated by this project and has not been approved for clinical use.
